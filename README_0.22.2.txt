菁云部署系统 0.22.2（硬件识别与兼容性提示版）
============================================

基线：0.22.1 简洁稳定版。

本版新增：
1. PXE 客户端自动上报 CPU 架构、CPU 型号、逻辑核心数、内存总量和物理硬盘信息。
2. “已注册客户端”列表新增：架构、CPU、核心、内存、最大硬盘容量等列，保留标题排序。
3. 单台下发选择镜像时显示客户端硬件与镜像架构；CPU 架构不匹配只警告，不强制阻止，由管理员选择“是/否”。
4. 当前组批量下发/组播时，在最终确认窗口集中列出 CPU 架构不匹配的客户端数量与名称；仍可确认继续建立整组任务。
5. 客户端领取任务时不再因 CPU 架构不同而被维护环境二次阻止；任务日志会保留“管理员已确认继续下发”的兼容性警告。
6. 组播逻辑保持：选择具体分组 → 设置当前组任务 → 组播同步下发；为组内每台客户端建立 MAC 定向任务，全部就绪后统一发送。
7. Deepin 25、Windows、银河麒麟、UOS、中科方德个性化逻辑保持不变。

说明：
- CPU 架构不匹配仅作为提示，不是硬性限制。
- 硬盘容量仍由维护环境执行实际写盘安全检查；本版本没有取消磁盘物理容量保护。
- 新硬件信息需要客户端用 0.22.2 PXE 环境启动/注册或领取任务后才会刷新；旧注册记录在再次 PXE 启动前会显示“未知”。

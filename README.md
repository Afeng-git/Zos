菁云镜像部署系统 0.21.1 龙芯组播/个性化测试版（无HTTP、无数据库）
=================================================

运行：
  pip install PyQt5 psutil
  以管理员/root权限运行：python jingyun_simple_manager.py

多架构引导（本版重点）：
  - 一个管理端同时提供x86/x86_64、ARM64和龙芯LoongArch64三套独立维护环境。
  - DHCP按UEFI架构号发送对应iPXE；进入iPXE后再按buildarch选择内核和initrd，禁止跨架构误启动。
  - x86/x86_64：成熟功能，支持注册、RAW整盘上传/下发、单播、组播及部署后个性化。
  - ARM64：硬件测试版，采用FOG FOS ARM64内核和根文件系统，已嵌入同一ZOS代理；
    计划支持注册、RAW整盘上传/下发、单播和组播。具体网卡、存储控制器兼容性须在目标设备验证。
  - 龙芯LoongArch64：采用openEuler 24.03 LTS LoongArch64 PXE内核/initrd，支持注册、
    自动磁盘枚举、RAW整盘单播/可靠组播上传下发、逐台进度回报及Linux部署后个性化。
  - 龙芯可靠组播使用ZOSMC1窗口确认协议，不依赖LoongArch64版udp-receiver：每个窗口必须由
    全部客户端ACK；丢失的数据包按NACK重发，最终核对压缩文件总字节和SHA-256。
  - 龙芯Linux个性化支持ext2/3/4、XFS、Btrfs及LVM根分区，支持计算机名、固定IP、
    DHCP、网关和DNS；网络设置由按MAC定位网卡的一次性systemd服务在首次启动应用。
  - 龙芯不执行x86 Windows个性化；x86 Windows镜像不能在龙芯CPU启动。
  - 新上传镜像记录源CPU架构，已知架构不一致时管理端和客户端都会禁止写盘。
  - 管理程序本身可在Windows或Linux运行；ARM64/龙芯Linux需安装对应架构的Python 3、PyQt5和psutil。
    若要由非x86管理端发起组播，还需要系统PATH中存在该架构原生udp-sender。
  - 本版不包含ARM32、MIPS或32位龙芯维护环境。

多架构TFTP文件：
  - x86_64：tftp/x86_64/zos/bzImage + init.xz
  - ARM64：tftp/arm64/zos/Image + init.cpio.gz
  - LoongArch64：tftp/loongarch64/zos/vmlinuz + initrd.xz
  - ARM64和龙芯都需要UEFI网络启动；旧式BIOS的undionly.kpxe仅用于x86。

上传镜像：
  1. 选择连接客户端的网卡，点击“开启 PXE + DHCP”。
  2. 客户端先PXE启动并选择“Register this computer”完成注册。
  3. 管理端选中该客户端，点击“设置选中客户端任务（上传/下发）”。
  4. 选择“下次开机自动上传模板”，填写镜像名称、源盘和完成后动作。
  5. 客户端再次PXE启动后自动领取定向上传任务。
  6. 完成后镜像保存为 images/*.img.zst，旁边同时保存安全校验元数据。

下发镜像：
  1. 客户端先完成注册，管理端选中该客户端。
  2. 点击“设置选中客户端任务（上传/下发）”，选择“下次开机自动下发镜像”。
  3. 选择已上传的 RAW 整盘镜像；目标设备通常保持 auto。
  4. 客户端再次PXE启动后自动领取定向下发任务。
  5. 客户端自动识别可写物理盘并校验容量；目标盘不小于源盘才会开始写入。

客户端注册与自动任务：
  1. 管理端先填写客户端分组（逗号分隔），第一项为默认组，并点击“保存客户端分组”。
  2. 未注册客户端PXE启动后选择“Register this computer”。
  3. 客户端名称直接回车使用系统主机名；分组直接回车使用管理端默认组。
  4. 分组输入 ? 可查询管理端分组，再输入序号选择。
  5. 注册完成后，客户端可选择 1 重启或 2 关机。
  6. MAC、名称、组、主机名、IP和磁盘信息会写入管理端。
  7. 管理端选择客户端，再点击“设置选中客户端任务”。
  8. 可设置“下次开机自动上传模板”或“下次开机自动下发镜像”。
  9. 自动任务绑定客户端MAC并且只执行一次，其他客户端不会误领。
  10. 没有自动任务时，PXE菜单默认倒计时10秒从本地硬盘启动；秒数可在管理端修改。
  11. RAW上传和下发时，客户端屏幕显示已处理字节、传输速度和实时进度。

分组任务、批量唤醒和导出：
  1. 在“列表筛选”中选择具体分组，点击“设置当前组任务”。
  2. 组上传会为每台客户端建立独立镜像任务，名称可使用 {group}、{hostname}、{mac}、{date}。
  3. 组部署可选择“单独下发”或“组播同步下发”，都使用同一个RAW整盘镜像。
  4. 单独下发仍通过TCP 8090逐台独立传输；各客户端互不等待。
  5. 组播同步下发会等本次组任务中的所有客户端PXE上线，并完成目标盘和容量检查。
  6. 管理端显示已就绪数量；少一台都不会启动udp-sender，也不会开始覆盖客户端硬盘。
  7. 全部就绪后只发送一条可靠组播流；x86/ARM使用UDPcast，龙芯使用ZOSMC1，
     客户端通过丢包重传协议接收并显示写盘进度。
  8. 可选择“千兆高速（推荐）”“兼容稳定”或“高速网络/SSD”三种组播速度。
  9. 部署任务表按每台MAC分别显示实际写盘进度、已写入容量、开始时间和耗时。
  10. 组播使用会话独立的两个UDP端口（任务信息中会显示）；交换机和VLAN需允许组播通信。
  11. 客户端列表支持Ctrl/Shift多选，再点击“唤醒选中客户端”；也可“唤醒当前组”。
  12. WOL通过所选部署网卡向当前子网广播地址的UDP 7和9端口重复发送。
  13. 客户端须在BIOS和网卡中启用网络唤醒，通常要求有线网卡和同一二层网络。
  14. “导出客户端列表”支持Excel .xlsx和UTF-8 TXT；选择分组时只导出当前组。
  15. “导入客户端”支持.xlsx、UTF-8/GB18030的.txt和.csv；至少需要MAC列，
      可同时包含客户端名称、IP和组。再次导入同一MAC会更新原记录，不会产生重复客户端。
  16. 客户端和任务列表均支持Ctrl/Shift多选及“全选”；可批量删除。
      删除客户端时取消其待执行任务，但保留历史任务和镜像；正在执行的客户端/任务禁止误删。
      删除组播任务时会按完整组播会话一起删除，镜像文件不会随任务记录删除。

现代化界面：
  - 使用深蓝侧栏、白色信息卡片、粉蓝强调色和统一表格样式，风格接近现代管理控制台。
  - PXE启停集中在左侧，网络、客户端、任务和日志仍在同一窗口中，不改变原有操作流程。

按注册信息分别设置名称和静态IP（可选）：
  1. 新建单机或分组“下发镜像”任务时，“修改计算机名”和“设置固定IP”可分别勾选。
  2. 未勾选修改计算机名时保留镜像原名称；未勾选固定IP时明确恢复IPv4和DNS自动获取，
     即使模板原来使用固定IP也不会沿用旧地址。
  3. 每台任务仍以MAC地址定向；名称和IP分别取该MAC在“已注册客户端”里的名称和IP。
  4. Windows名称会转换为ASCII安全名称并限制为15个字符；不合规名称自动使用ZOS加MAC后6位。
  5. Windows 7及以上版本采用ZOS早期离线个性化逻辑：镜像写盘后、Windows启动前，
     直接修改离线SYSTEM注册表中的实际ControlSet、ControlSet001/002/003，无需安装客户端。
  6. Linux镜像写完后按所选项目修改；固定IP或恢复DHCP均使用一次性systemd服务按MAC找到网卡，
     支持NetworkManager、network-scripts、systemd-networkd和ifupdown。
  7. 如果Windows分区因快速启动/休眠而不能读写，或系统分区格式不受支持，镜像下发仍会完成，
     任务状态显示“完成但个性化失败”，不会误报为全部成功。
  8. 计算机名直接写入SYSTEM注册表并在写回后重新读取验证；这部分完全不依赖Windows登录、
     PowerShell、计划任务或常驻服务，兼容Windows 7、8/8.1、10、11。
  9. 静态IP优先直接写入离线SYSTEM注册表：从活动ControlSet中查找持有DHCP租约的接口GUID，
     写入EnableDHCP=0、IPAddress、SubnetMask、DefaultGateway和NameServer。
  10. 固定IP任务始终写入一次性PowerShell 2.0兼容校验动作，按注册MAC匹配实际网卡，
      设置并复核IP、网关和DNS，成功后自动删除，不安装常驻代理。
  11. 如果NTFS处于休眠/快速启动状态，ZOS先尝试ntfs-3g和NTFS3挂载；挂载不可用时使用
      ntfscat/ntfscp直接读取、修改、写回并复核SYSTEM注册表文件。
  12. 银河麒麟V10部署个性化支持LVM自动激活及XFS nouuid安全挂载；所有挂载操作有超时保护。
      首次启动服务使用/bin/bash执行并兼容未激活的NetworkManager连接，个性化异常只标记警告，
      已完成的镜像写盘仍会正常报告并执行重启/关机动作。

Linux兼容范围：
  - RAW整盘上传和下发不依赖发行版，GPT/MBR、EFI和所有分区会原样复制。
  - 部署后“修改计算机名/固定IP”已覆盖银河麒麟V10、Ubuntu/Debian、UOS/Deepin、
    CentOS/RHEL/Rocky/Alma和openSUSE/SLES常用布局；支持ext2/3/4、XFS、Btrfs，
    以及NetworkManager、network-scripts、systemd-networkd、ifupdown。
  - LUKS加密根分区、ZFS根分区、OSTree/不可变系统、特殊软RAID等布局不能保证离线个性化；
    遇到这类系统请不勾选名称/IP，镜像本身仍可正常上传和下发。

网络默认值：
  - 网关：服务器IP前三段不变，最后一段默认为254；可删除留空。
  - DNS1：223.6.6.6；可删除留空。
  - DNS2：114.114.114.114；可删除留空。
  - DHCP会同时下发填写的网关和两个DNS；固定IP个性化也使用相同设置。

组成：
  - DHCP：程序内置，UDP 67。
  - TFTP：程序内置，UDP 69；iPXE菜单、ZOS内核和init.xz全部通过TFTP读取。
  - 镜像上传/单独下发：独立TCP 8090，不是HTTP。
  - 组播下发：TCP 8090只负责任务与就绪协调；x86/ARM镜像由UDPcast传输，
    龙芯镜像由内置ZOSMC1可靠组播传输。
  - 任务：data/tasks.json。
  - 终端：data/nodes.json。
  - 注册终端：data/registrations.json。
  - 镜像：images/*.img.zst。
  - 没有SQLite、SQL、MariaDB、Werkzeug、Flask或HTTP服务。

安全规则：
  - 只有管理端已有排队的“下发”任务，并且客户端主动选择 Deploy，才会写盘。
  - 当前只下发 RAW 整盘镜像，因此GPT/MBR、EFI分区、系统分区和数据分区一并恢复。
  - 目标盘全部现有分区和数据会被覆盖，不能撤销。
  - 目标盘必须与源盘同容量或更大；更大的多余空间暂时保持未分配。
  - 多硬盘机器建议在任务中明确目标设备，避免自动选择不符合预期。
